# 🛍️ Neo Geek

Loja virtual fictícia com temática geek, desenvolvida para praticar HTML e CSS.

## 🔗 Acesse o projeto

👉 https://andressadonrodrigues08.github.io/Projeto-loja-neo/index.html 

---

## 📌 Sobre o projeto

O **Neo Geek** é um site de vitrine de produtos geek (camisetas, canecas e posters), criado com foco em prática de estruturação e estilização de páginas web.

O projeto simula uma loja online, apresentando produtos com imagem, nome, preço e botão de compra.

---

## 🚀 Tecnologias utilizadas

* HTML5
* CSS3

---

## 🎨 Funcionalidades

* Layout com menu de navegação no topo
* Banner principal personalizado
* Exibição de produtos em formato de cards
* Botões de compra
* Rodapé com informações e redes sociais


---

## 📚 Aprendizados

Durante o desenvolvimento deste projeto, foram praticados:

* Organização de arquivos
* Uso de Flexbox para layout
* Estilização de componentes (cards, botões, menu)

---

## 💡 Observação

Este projeto é apenas para fins de estudo e não possui funcionalidades reais de compra.
